# نمونه استفاده از irshop

نمونه‌های زیر **الگوی قالب خروجی** هستند، نه داده واقعی بازار. عامل باید هر قیمت، موجودی، نام فروشنده و URL را در زمان درخواست از صفحه قابل‌دسترسی استخراج کند.

## جستجوی ساده

درخواست نمونه:

~~~text
قیمت فعلی Samsung Galaxy A56 را در فروشگاه‌های ایرانی پیدا کن و لینک محصول هر فروشنده را بده.
~~~

## قالب پاسخ لازم

~~~markdown
## مقایسه قیمت: [نام دقیق محصول و نسخه]

| # | محصول و مدل دقیق | قیمت (تومان) | فروشگاه / فروشنده | موجودی | لینک مستقیم |
|---:|---|---:|---|---|---|
| 1 | [عنوان و نسخه‌ای که واقعاً بررسی شده] | [قیمت نرمال‌شده یا نامشخص] | [فروشنده تأییدشده] | [موجود / نامشخص] | [مشاهده محصول](https://example.com/product) |

### خلاصه
- نتایج قابل مقایسه: [تعداد پیشنهادهای یکتا]
- ارزان‌ترین گزینه: [فروشنده و قیمت، فقط در صورت وجود پیشنهاد موجود و قابل مقایسه]
- میانگین قیمت: [فقط برای یک مدل/نسخه و قیمت‌های معتبر یکسان]
- محدودیت‌ها: [سایت‌های بررسی‌نشده، موجودی نامشخص، هزینه ارسال بررسی‌نشده]
~~~

URL مثال صرفاً برای نمایش Markdown است؛ هرگز آن را به‌عنوان نتیجه واقعی نمایش ندهید.

## قیمت فارسی

ورودی نمونه برای ابزار کمکی:

~~~bash
python scripts/parse_price.py "۹۶٬۵۰۰٬۰۰۰ تومان"
~~~

خروجی باید مبلغ نرمال‌شده 96500000 تومان و وضعیت قیمت ok را نشان دهد. مبلغ بدون واحد صریح باید unit_unknown باشد، مگر اینکه عامل از متن همان صفحه واحد تومان را تأیید کرده باشد.

## بررسی تست‌ها

~~~bash
python -m unittest discover -s scripts -p "test_*.py"
~~~

این Skill نمودار تاریخی، هشدار پس‌زمینه، کد تخفیف، تحلیل نظرات، لیست خرید، خروجی CSV/JSON یا برآورد ارسال را پیاده‌سازی نمی‌کند.
