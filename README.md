# irshop — جستجو و مقایسه قیمت فروشگاه‌های ایرانی

irshop یک **Agent Skill** برای جستجوی زنده محصولات در فروشگاه‌های ایرانی و برگرداندن جدول مقایسه قیمت است. این مخزن یک خزنده مستقل یا سرویس دائمی اجرا نمی‌کند؛ عامل باید از ابزار مرورگر/وبی که محیطش واقعاً در اختیارش گذاشته استفاده کند.

## قابلیت‌های فعلی

- شروع جستجو از ترب و سپس بررسی فروشگاه‌های عمومی یا تخصصی مرتبط.
- بررسی صفحه محصول برای تطبیق مدل و نسخه، قیمت فعلی، فروشنده و وضعیت موجودی.
- نرمال‌سازی اعداد فارسی و عربی و تبدیل ریال به تومان فقط با واحد صریح یا تأییدشده.
- حذف پیشنهادهای تکراری بدون ادغام فروشنده‌ها یا مدل‌های متفاوت.
- خروجی جدول Markdown با حداکثر ۱۰ پیشنهاد، لینک منبع و خلاصه‌ای شامل ارزان‌ترین گزینه و میانگین/بازه قابل‌مقایسه.

## نصب

برای نصب با ابزار Skills CLI که در محیط عامل شما پشتیبانی می‌شود:

~~~bash
npx skills add Demonariya/irshop
~~~

یا مخزن را دریافت کنید و پوشه آن را در مسیر Skills مورد پشتیبانی عامل خود قرار دهید:

~~~bash
git clone https://github.com/Demonariya/irshop.git
~~~

بعد از نصب بررسی کنید که عامل فایل SKILL.md را بارگذاری می‌کند و ابزار مرورگر یا جستجوی وب لازم واقعاً در دسترس است. نام ابزارها بین محیط‌ها متفاوت است؛ این Skill عمداً وجود ابزار خاصی را فرض نمی‌کند.

## استفاده

از عامل بخواهید جستجوی زنده انجام دهد، برای نمونه:

~~~text
قیمت فعلی Samsung Galaxy A56 را در فروشگاه‌های ایرانی پیدا کن و با لینک مستقیم و وضعیت موجودی مقایسه کن.
~~~

خروجی شامل ستون‌های «محصول و مدل دقیق»، «قیمت (تومان)»، «فروشگاه / فروشنده»، «موجودی» و «لینک مستقیم» است. قیمت‌های با واحد نامشخص نباید در رتبه‌بندی یا میانگین وارد شوند.

## فروشگاه‌ها و راهنمای استخراج

فهرست و یادداشت‌های اختصاصی هر سایت در **references/shops.json** قرار دارد. این الگوهای URL و selectorها راهنما هستند، نه تضمین ساختار فعلی سایت؛ عامل باید ساختار زنده صفحه را بررسی کند. برای سایت‌های تخصصی فقط هنگام مرتبط‌بودن دسته محصول جستجو انجام می‌شود.

## ابزار نرمال‌سازی قیمت

اسکریپت Python مستقل از کتابخانه‌های ثالث است و خودش وب‌اسکرپینگ انجام نمی‌دهد:

~~~bash
python scripts/parse_price.py "۹۶٬۵۰۰٬۰۰۰ تومان"
python scripts/parse_price.py "۹۶٬۵۰۰٬۰۰۰" --assume-toman
python -m unittest discover -s scripts -p "test_*.py"
~~~

از گزینه assume-toman فقط وقتی استفاده کنید که واحد تومان از متن همان صفحه روشن باشد.

## خارج از محدوده فعلی

موارد زیر در نسخه فعلی پیاده‌سازی نشده‌اند و نباید به‌عنوان قابلیت آماده تبلیغ شوند: تاریخچه/نمودار قیمت، هشدار پس‌زمینه، اعتبارسنجی کد تخفیف، تحلیل نظرات، لیست خرید پایدار، خروجی CSV/JSON، برآورد زمان ارسال، مقایسه اقساط و نقشه فروشگاه‌ها.

## محدودیت و حریم دسترسی

قیمت و موجودی ممکن است تغییر کند. هزینه ارسال و تخفیف‌های مشروط فقط وقتی لحاظ می‌شوند که منبع آن‌ها را صریحاً نشان دهد. در برابر CAPTCHA، محدودیت دسترسی، 403 یا 429، عامل باید تلاش را متوقف کند و از منابع عمومی دیگر استفاده کند؛ دور زدن محدودیت‌ها جزو عملکرد این Skill نیست.

## مشارکت

- اصلاحات را همراه با شواهد ساختار واقعی سایت پیشنهاد دهید.
- selectorهای تأییدنشده را به‌عنوان «راهنما» مشخص کنید.
- برای تغییر رفتار پارسر، تست‌های scripts/test_parse_price.py را به‌روزرسانی کنید.
